# Lumaris v1.1.0

## 中文

### 更新
- 新增 HDR 模式下的 SDR 内容亮度调节。
- 支持多显示器分别调节 SDR 内容亮度。
- 仅在系统与显示器实际支持时显示 SDR 滑块。

### 修复
- 浮窗会根据 SDR 控件数量自动调整高度。

### 说明
- SDR 内容亮度仅在 Windows HDR 已开启时可用，支持情况取决于系统版本与显卡驱动。
- 覆盖安装前请退出托盘中的 Lumaris。
- 配置目录：`%LOCALAPPDATA%\Lumaris`（升级不丢设置）。

---

## English

### Highlights
- Added SDR content brightness control while HDR is active.
- Added per-display SDR controls for multi-monitor setups.
- The SDR slider only appears when the system and display support it.

### Fixes
- The flyout now resizes for the available SDR controls.

### Notes
- SDR content brightness requires Windows HDR and depends on OS and graphics-driver support.
- Quit Lumaris from the tray before upgrading.
- Settings stay in `%LOCALAPPDATA%\Lumaris`.
