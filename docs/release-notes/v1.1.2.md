## Lumaris 1.1.2

### 更新

- 新增白天 / 夜间亮度记忆模式：分别记忆每台显示器亮度，在浮窗底栏一键切换，重启后保留。实现 [Issue #1](https://github.com/Elnyxn/Lumaris/issues/1)。
- 亮度模式默认关闭，可在设置中启用；关闭隐藏入口并保留记录。各屏支持滑条与百分比编辑，保存不会改动实际亮度，应用时才调整屏幕。
- 模式按显示器身份匹配，恢复已连接的可调节屏幕；重新保存时保留暂时断开屏幕的旧记录。
- 新增「浮窗滚动阈值」设置，可选择主屏可用高度的 20–100%，默认 50%，内容超过上限才滚动。
- 配置保存串行化，避免后台亮度缓存保存覆盖新保存的模式。

若更换连接口或 Windows 重新编号导致显示器身份变化，请重新保存模式。

### Changes

- Add per-display Day / Night brightness presets, saved across restarts and accessible with one click from the flyout. Implements [Issue #1](https://github.com/Elnyxn/Lumaris/issues/1).
- Brightness modes are off by default. Enable them in settings and edit each display with a slider and percentage input. Saving does not change the screens; applying does. Disabling hides the controls and keeps saved modes.
- Match presets by display identity, apply to connected adjustable displays, and keep unplugged displays when re-saving.
- Add a customizable flyout height limit of 20–100% of the primary display's usable height, with a 50% default.
- Serialize configuration writes so background brightness cache saves cannot overwrite a newly saved preset.

If a port change or Windows display renumbering changes a display's identity, save the modes again.

### 使用 / Usage

在「设置 → 亮度模式」启用功能，编辑并保存白天和夜间亮度；之后从浮窗点击模式切换。

Enable **Brightness modes** in settings, edit and save Day and Night, then switch with the flyout buttons.
