## Lumaris 1.1.1

### 更新

- 修复快速或连续使用亮度快捷键时，松键回调与主线程相互等待导致的未响应。
- 多显示器列表按实际内容完整展开，包含 SDR 与状态行；超过主屏可用高度的 50% 才显示滚动条，适配 DPI 缩放。
- 更新暖灰与香槟金太阳 Logo，同步应用、托盘、安装包及中英文 README 图标。

### Changes

- Fix a deadlock between shortcut release callbacks and the UI thread during repeated brightness hotkeys.
- Expand monitor lists to fit their content, including SDR and status rows. Scroll only above half the primary display's usable height, accounting for DPI scaling.
- Refresh the warm charcoal and champagne-gold sun icon across the app, tray, installer, and both READMEs.

### 下载 / Downloads

- `Lumaris-Setup-1.1.1.exe`：Windows 10/11 x64 安装包。
- `Lumaris-portable-1.1.1.zip`：解压即用。
- 校验文件：`SHA256SUMS.txt`。

需要 Microsoft Edge WebView2 Runtime。升级保留现有配置。
